## ✨ Features Implemented (Task 3 Phase 1 Requirements)

### 1. CSS & JavaScript
- External `style.css` - responsive grid, sticky navbar, hover effects
- External `script.js` - interactive logic

### 2. Drop-down Menu ✅
- **Courses ▾** hover dropdown (Desktop) / click (Mobile)
- Links: Long-term Courses / Short Courses / Pricing Table / Quote Calculator

### 3. Table ✅
- Pricing Table in `courses.html` - Course Name | Duration | Price | Category
- 7 courses: 4 Long-term (12-week, R1500) + 3 Short (6-week, R750)
- Hover effect, responsive

### 4. Error Handling ✅
**Calculator:**
- `Course already added!` - prevents duplicate
- `Please select at least one course to request a quote`

**Contact Form:**
- Name must be at least 3 characters
- Email must be valid (regex check)
- Phone must be 10 digits (e.g. 0821234567)
- Message must be at least 10 characters
- Inline errors under each field + success message

### 5. Quote Calculator & Discount Logic
- Add to Quote buttons on each course card
- Subtotal, Course Count, Discount, Total live calculation
- Discount Rules: 2 courses = 5% | 3 courses = 10% | 4+ courses = 15%
- Clear Selection + Request Quote
- Quote saved to `localStorage`

### 6. Responsive Design
- Hamburger menu on mobile (max-width 768px)
- Grid collapses to single column
